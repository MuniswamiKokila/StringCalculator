# String Calculator Kata – TDD Demo

This solution showcases clean code and TDD best practices using Java, Maven, and JUnit. Each step is documented with meaningful commit messages, inline comments, and full Javadocs.

Technologies: Java 17, Maven, JUnit 5, Git.

## Problem Features
- Supports comma, newline, and custom single-character delimiters.
- Robust error handling, including custom exception messages for negative inputs.
- Comprehensive unit tests show evolutive steps.
